Section 02

The Kalman Filter "Rosetta Stone"

Every research engineer understands the standard linear Kalman filter (Δx = K(y - Hx), P = (I - K)P). But why can't we just plug a unit embedding into a regular Kalman filter?

The Manifold Breakdown: In Euclidean space, linear vector addition x + Kv stays in ℝn. On the unit hypersphere, vector addition breaks the constraint: ||x + Kv|| ≠ 1. If you renormalize naively after standard Euclidean addition, the uncertainty ellipses warp, covariance geometry becomes invalid, and the filter diverges.

To bridge the gap, here is the exact translation from the textbook Kalman filter equations to their spherical counterparts:

State Belief Mean vector x̂ ∈ ℝn Mean unit vector μ ∈ Sd-1 Mean unit vector γ1 ∈ S2 Mean unit vector μ ∈ Sd-1
Uncertainty Covariance matrix P ∈ ℝn×n Inverse concentration σ2 ≈ 1/κ · I σ12 ≈ 1/(κ-2β), σ22 ≈ 1/(κ+2β) Full (d-1) covariance P ∈ ℝ(d-1)×(d-1)
Measurement Noise Covariance matrix R Scalar noise σobs2 ≈ 1/κobs Anisotropic noise (κobs, βobs) Tangent noise covariance R
Innovation (Residual) ṽ = y - Hx̂ (vector difference) θ = arccos(μTy) (geodesic angle) Tangent offset v = y - (γ1Ty)γ1 Log-Map: v = Logμ(y) ∈ Tμ
Kalman Gain K = P HT (H P HT + R)-1 Weight ratio: κobs / (κprior + κobs) Tensor weight in natural basis Exact tangent gain: K = P(P + R)-1
State Update x̂ ← x̂ + K ṽ μ ← (κμ + κobsy) / ||κμ + κobsy|| γ1 ← ηpost / ||ηpost|| Exp-Map: μ ← Expμ(Kv)

Mental Model: vMF

A scalar Kalman filter running on a sphere. It weights prior and measurement purely by their scalar precisions (κprior vs κobs). Fast and foolproof, but assumes identical noise in every direction.

Mental Model: Kent

A 2D Kalman filter with full 2×2 covariance wrapped onto the surface of a 3D sphere. It can prioritize horizontal over vertical certainty, but cannot scale past 3D.

Mental Model: R-EKF

A standard textbook N-D Kalman filter that executes inside the local tangent plane and re-centers its coordinate origin at the moving mean μ via the Exponential Map after every step.

Section 03

von Mises-Fisher (vMF): The Isotropic Baseline

The vMF distribution is parameterized by a mean direction vector μ ∈ Sd-1 and a single scalar concentration κ ≥ 0:

f(x; μ, κ) = Cd(κ) · exp(κ μT x)

Because density depends strictly on the inner product μTx = cos(θ), the dispersion is rotationally symmetric. A (1 - α) credible region is always a perfect spherical cap with angular radius:

cos(θα) = 1 + (1 / κ) · ln(α + (1 - α)e-2κ)  &implies;  θ95% ≈ √(5.99 / κ) radians

Bayesian Update Rule: The natural parameter vector is η = κ μ. When an observation yt arrives with observation confidence κobs:

ηt = ηt-1 + κobs yt    κt = ||ηt||,   μt = ηt / κt

Section 04

Kent Distribution (FB5): Directional Anisotropy

When viewing an object from consecutive camera angles (e.g. orbiting around azimuth), the uncertainty is anisotropic: large variance along the camera motion path, but small variance orthogonal to it.

The Kent distribution (FB5) models this via 5 parameters: orthonormal axes γ1, γ2, γ3, concentration κ, and ovalness β (0 ≤ 2β < κ):

f(x) ∝ exp(κ γ1Tx + β [(γ2Tx)2 - (γ3Tx)2])

In the tangent plane, the two orthogonal variances are:

σmajor2 ≈ 1 / (κ - 2β),    σminor2 ≈ 1 / (κ + 2β)

Observation Noise Characterization: An observation from camera viewpoint yt arrives with its own major noise axis (e.g. motion blur) and ovalness βobs. The conjugate update sums natural linear and quadratic matrices: ηpost = η + ηobs and Apost = A + Aobs, then projects Apost onto the tangent plane of the new mean to extract the new elliptical axes.

Section 05

Riemannian EKF for 128D+ Hypersphere Embeddings

While the Kent distribution is mathematically elegant, it cannot scale past 3D because normalizing the matrix exponential in d = 128 is intractable.

The Production Solution: The Riemannian Extended Kalman Filter (R-EKF). Instead of trying to maintain a closed-form distribution across the curved manifold, it maps the state to the local Euclidean tangent space TμSd-1 ≅ Rd-1:

  • Step 1 (Log Map): Project incoming unit vector y to tangent innovation: v = Logμ(y) = (θ / sin θ)(y - cos θ μ).
  • Step 2 (Kalman Update): Perform a standard Kalman update on the (d-1) plane: K = P(P + R)-1, δ = Kv.
  • Step 3 (Exp Map): Retract the updated vector back to the unit sphere: μnew = Expμ(δ).
  • Step 4 (Covariance Retraction): Transport Pnew = Π (I - K) P Π.

Computational Cost in 128D: The tangent covariance matrix P is 127 × 127 Float32 (64.5 KB). A full matrix solve takes under 0.05 milliseconds on a standard CPU thread (>20,000 updates/sec).

Section 06

Production Decision Guide

Choose vMF when:

  • You only have a scalar confidence per frame (e.g., MagFace norm ||z|| or detector score).
  • You want ultra-minimal computation (<100 FLOPs per frame).
  • Camera viewpoints change randomly without a dominant motion axis.

Choose Kent (FB5) when:

  • Your embedding/state is explicitly in 3D (e.g., camera orientation, 3D surface normal, magnetic vector).
  • You have clear anisotropic noise (e.g., azimuth vs elevation blur).
  • You need exact closed-form directional statistics on S2.

Choose Riemannian EKF when:

  • Your embedding dimension is high (d = 128, 256, 512, 768).
  • Different feature semantic dimensions have unequal reliability.
  • You want full anisotropic covariance without matrix normalization bottlenecks.

1. von Mises-Fisher Bayesian Filter (Any Dimension)

import numpy as np

class VMFFilter:
    """
    von Mises-Fisher Bayesian filter on S^{d-1}.
    Tracks mean vector mu and concentration kappa via natural vector eta = kappa * mu.
    """
    def __init__(self, dim=128, mu_prior=None, kappa_prior=5.0):
        self.d = dim
        if mu_prior is None:
            self.mu = np.zeros(dim); self.mu[0] = 1.0
        else:
            self.mu = mu_prior / np.linalg.norm(mu_prior)
        self.kappa = float(kappa_prior)
        self.eta = self.kappa * self.mu

    def predict(self, decay_factor=0.98):
        """Optional motion dispersion / uncertainty growth."""
        self.eta *= decay_factor
        self.kappa = np.linalg.norm(self.eta)
        self.mu = self.eta / max(self.kappa, 1e-7)

    def update(self, y_obs, kappa_obs):
        """Conjugate Bayesian update: eta_t = eta_{t-1} + kappa_obs * y_obs."""
        y_obs = y_obs / np.linalg.norm(y_obs)
        self.eta += kappa_obs * y_obs
        self.kappa = np.linalg.norm(self.eta)
        self.mu = self.eta / self.kappa
        return self.mu, self.kappa

2. Kent Distribution (FB5) Anisotropic Filter (3D)

import numpy as np

class KentFilter3D:
    """
    Kent (FB5) Anisotropic Bayesian Filter on S^2.
    Tracks mean gamma1, major axis gamma2, minor axis gamma3, concentration kappa,
    and ovalness beta via natural linear vector eta and quadratic matrix A.
    """
    def __init__(self, mu_prior=None, kappa_prior=8.0, beta_prior=0.0, psi_rad=0.0):
        if mu_prior is None:
            self.gamma1 = np.array([0.0, 0.0, 1.0])
        else:
            self.gamma1 = mu_prior / np.linalg.norm(mu_prior)
            
        self.kappa = float(kappa_prior)
        self.beta = float(beta_prior)
        
        # Build initial orthogonal axes in tangent plane
        arb = np.array([0, 0, 1]) if abs(self.gamma1[2]) < 0.9 else np.array([1, 0, 0])
        u = np.cross(self.gamma1, arb); u /= np.linalg.norm(u)
        v = np.cross(self.gamma1, u)
        
        self.gamma2 = np.cos(psi_rad) * u + np.sin(psi_rad) * v
        self.gamma3 = -np.sin(psi_rad) * u + np.cos(psi_rad) * v
        
        # Natural parameters: eta (linear) and traceless matrix A (quadratic)
        self.eta = self.kappa * self.gamma1
        self.A = self.beta * (np.outer(self.gamma2, self.gamma2) - np.outer(self.gamma3, self.gamma3))

    def update(self, y_obs, kappa_obs, beta_obs=0.0, major_noise_dir=None):
        """
        Conjugate Bayesian update with anisotropic observation noise:
          y_obs: unit vector of shape (3,)
          kappa_obs: average measurement precision
          beta_obs: noise ovalness (0 <= 2*beta_obs < kappa_obs)
          major_noise_dir: orientation of the blurry/high-uncertainty tangent axis
        """
        y_obs = y_obs / np.linalg.norm(y_obs)
        eta_obs = kappa_obs * y_obs
        
        # Construct observation quadratic matrix A_obs
        if major_noise_dir is not None and beta_obs > 0:
            v_maj = major_noise_dir - np.dot(major_noise_dir, y_obs) * y_obs
            v_maj /= (np.linalg.norm(v_maj) + 1e-9)
            v_min = np.cross(y_obs, v_maj)
            A_obs = beta_obs * (np.outer(v_maj, v_maj) - np.outer(v_min, v_min))
        else:
            A_obs = np.zeros((3, 3))

        # 1. Exact Bayesian linear sum in natural parameter space
        self.eta += eta_obs
        self.A += A_obs

        # 2. Extract Kent parameters (Assumed Density Projection)
        self.kappa = np.linalg.norm(self.eta)
        self.gamma1 = self.eta / self.kappa

        # Project A onto tangent plane of updated mean gamma1
        P = np.eye(3) - np.outer(self.gamma1, self.gamma1)
        B = P @ self.A @ P

        eigvals, eigvecs = np.linalg.eigh(B)
        idx = np.argsort(eigvals)
        eigvals, eigvecs = eigvals[idx], eigvecs[:, idx]

        # Extract major and minor tangent axes
        self.gamma3 = eigvecs[:, 1]  # minor axis
        self.gamma2 = eigvecs[:, 2]  # major axis
        self.beta = float(np.clip((eigvals[2] - eigvals[1]) / 4.0, 0.0, (self.kappa / 2.0) - 0.1))

        return self.gamma1, self.gamma2, self.gamma3, self.kappa, self.beta

    def get_credible_ellipse_axes(self):
        """Returns 95% semi-major and semi-minor angular radii in degrees."""
        c2 = 5.991  # Chi-Square 95% (2 DoF)
        a = np.sqrt(c2 / max(0.1, self.kappa - 2 * self.beta))
        b = np.sqrt(c2 / max(0.1, self.kappa + 2 * self.beta))
        theta_major_deg = np.degrees(np.arcsin(min(0.999, a)))
        theta_minor_deg = np.degrees(np.arcsin(min(0.999, b)))
        return theta_major_deg, theta_minor_deg

3. Production Riemannian EKF for 128D Hypersphere Embeddings

import numpy as np

class RiemannianSphereEKF:
    """
    Riemannian Extended Kalman Filter on the unit hypersphere S^{d-1}.
    Maintains mean on S^{d-1} and full (d-1) covariance on tangent plane T_mu.
    """
    def __init__(self, dim=128, initial_mu=None, initial_var=0.1):
        self.d = dim
        if initial_mu is None:
            self.mu = np.zeros(self.d); self.mu[0] = 1.0
        else:
            self.mu = initial_mu / np.linalg.norm(initial_mu)
            
        # Covariance on the (d-1) tangent space
        self.P = np.eye(self.d - 1) * initial_var

    def _get_tangent_basis(self, mu):
        """Generates orthonormal basis E of shape (d, d-1) for T_mu(S^{d-1})."""
        idx = np.argmin(np.abs(mu))
        arb = np.zeros(self.d); arb[idx] = 1.0
        u1 = arb - np.dot(arb, mu) * mu
        u1 /= np.linalg.norm(u1)
        
        # QR decomposition to construct remaining orthonormal basis
        A = np.random.randn(self.d, self.d - 1)
        A = A - np.outer(mu, mu @ A)
        Q, _ = np.linalg.qr(A)
        return Q

    def log_map(self, mu, y):
        """Projects point y on S^{d-1} to tangent vector v in T_mu."""
        cos_theta = np.clip(np.dot(mu, y), -1.0, 1.0)
        theta = np.arccos(cos_theta)
        if theta < 1e-7:
            return np.zeros(self.d)
        return (theta / np.sin(theta)) * (y - cos_theta * mu)

    def exp_map(self, mu, v):
        """Retracts tangent vector v back onto unit sphere S^{d-1}."""
        norm_v = np.linalg.norm(v)
        if norm_v < 1e-7:
            return mu
        return np.cos(norm_v) * mu + np.sin(norm_v) * (v / norm_v)

    def update(self, y_obs, R_tangent):
        """
        Bayesian update:
          y_obs: unit vector of shape (d,)
          R_tangent: measurement noise covariance of shape (d-1, d-1)
        """
        y_obs = y_obs / np.linalg.norm(y_obs)
        E = self._get_tangent_basis(self.mu)

        # 1. Log Map into tangent innovation coordinates
        v_ambient = self.log_map(self.mu, y_obs)
        z = E.T @ v_ambient

        # 2. Kalman Gain on (d-1) plane
        S = self.P + R_tangent
        K = self.P @ np.linalg.inv(S)

        # 3. Tangent Correction
        delta = E @ (K @ z)

        # 4. Exp Map: Retract mean to sphere
        self.mu = self.exp_map(self.mu, delta)

        # 5. Covariance update
        P_post = (np.eye(self.d - 1) - K) @ self.P
        self.P = 0.5 * (P_post + P_post.T) # Ensure symmetry

        return self.mu, self.P
