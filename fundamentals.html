Filtering fundamentals

From a circular uncertainty cap to a directional appearance update, with small interactive sphere examples.

A small flat workspace on a curved surface

A normalized embedding lies on a sphere. Near the current estimate, we can describe small differences on a flat tangent plane. We perform familiar covariance calculations there, then map the correction back onto the sphere.

A 128D normalized embedding has 127 tangent dimensions. The 3D sphere examples below make the geometry visible; they are teaching examples, not projections of actual 128D data.

Three ways to describe uncertainty

ModelFriendly interpretationRole in this tutorial
vMFOne concentration value; the same spread in every direction around the mean.A compact baseline on a sphere of any embedding dimension.
Kent (FB₅)An elongated footprint with major and minor directions.A directional observation on S², with an illustrative local update.
Riemannian EKFA local covariance that assigns different uncertainty to different combinations of features.A candidate approach for higher-dimensional appearance filtering.

These are useful analogies, not exact equivalents to scalar or Euclidean Kalman filters. A tangent Gaussian is a local approximation. Kent is one spherical distribution; it is not the only possible anisotropic family.

Optional: the vMF formula

p(y | μ, κ) ∝ exp(κ μᵀy). The density depends only on the angle from the mean.

For the S² illustration, the exact 95% cap satisfies cos θ = 1 + log(0.05 + 0.95 exp(−2κ)) / κ. This formula does not apply unchanged in 128D. Near a concentrated mean, tangent variance is approximately 1/κ in each tangent direction.

With independent vMF observations, natural parameters add: η ← η + κ_obs y, then κ = ‖η‖ and μ = η/κ when κ is nonzero.

Optional: what the Kent picture and update represent

The standard five-parameter Kent distribution lives on S². Its density is proportional to exp(κ γ₁ᵀy + β[(γ₂ᵀy)² − (γ₃ᵀy)²]), with orthonormal axes and 0 ≤ 2β < κ.

The amber footprint is an equal-density contour of that distribution. Its local observation variances are approximated by 1/(κ − 2β) and 1/(κ + 2β), rotated by the chosen noise direction. The “overall noise” slider sets the local isotropic scale before elongation.

For the update, we transport that local covariance from the observation to the prior and use a tangent Gaussian approximation. Blue and green are matching local quadratic contours. This is not an exact Kent posterior filter, and these outlines are not 95% probability regions. More general spherical families exist in higher dimensions; our interest in the tangent filter is its familiar local covariance machinery.

What the filter keeps track of

SymbolPlain meaning
μThe stored appearance direction.
PHow uncertain the filter is about that stored estimate.
RHow much uncertainty we assign to the incoming observation relative to our appearance model.
QUncertainty added between observations, even when we keep the predicted mean unchanged.

Increasing R in an unreliable direction has two related effects: it reduces that mismatch's association penalty, and reduces that observation component's influence on the appearance update.

Keeping the same predicted appearance is a workable starting assumption. It does not mean the appearance is truly constant. Q and an effective R let us investigate uncertainty before attempting a complete transition law.

What this does—and what still needs testing

Directional uncertainty gives us selective tolerance. It does not identify the correct match by itself. Two different vehicles can also differ along an unreliable direction.

The tangent approximation is most useful when uncertainty is local. Large appearance jumps, multiple plausible appearances, and long occlusions may need additional hypotheses or a richer model.

Optional implementation notes

The local update, in four steps
  1. Map the observation difference to the current tangent coordinates: z = Eᵀ Log_μ(y).
  2. For an identity appearance observation, calculate S = P + R and K = P S⁻¹.
  3. Map the correction back: μ_new = Exp_μ(E Kz).
  4. Update covariance and transform it into the new tangent coordinates.

E contains orthonormal tangent axes. P, R, and z must all use those same axes. Moving the mean requires a consistent covariance reset; simply normalizing the mean does not handle uncertainty geometry.

The filter widget maps local tangent uncertainty contours onto the sphere. The amber observation covariance is transported into the prior's tangent frame before the update; the posterior covariance is then reset into the new frame. These are qualitative local illustrations, not exact global spherical credible regions. The Add uncertainty button adds a small isotropic Q while holding the mean fixed.

For a general Euclidean observation matrix H, the gain uses HPHᵀ + R, and the simple covariance expression is P_post = (I − KH)P_prior. The examples use the more numerically robust Joseph form followed by a first-order sphere reset.

The manifold EKF reference explains why measurement covariance alignment and posterior reset matter.

"""Small NumPy examples for the spherical-filters tutorial.

These are local approximation examples, not a validated tracking system.
P and R use the filter's current tangent basis. An appearance/kinematics
joint model and data association are deliberately outside this example.
"""

import numpy as np


def unit(x):
    x = np.asarray(x, dtype=float)
    if x.ndim != 1 or x.size < 2 or not np.all(np.isfinite(x)):
        raise ValueError("Expected a finite vector with at least two entries")
    length = np.linalg.norm(x)
    if length < 1e-12:
        raise ValueError("A zero vector has no direction")
    return x / length


def tangent_basis(mu):
    """Deterministic orthonormal columns spanning the tangent at mu."""
    mu = unit(mu)
    identity = np.eye(mu.size)
    v = identity[:, 0] - mu
    if np.linalg.norm(v) < 1e-12:
        return identity[:, 1:]
    v /= np.linalg.norm(v)
    return (identity - 2 * np.outer(v, v))[:, 1:]


def log_map(mu, y):
    mu, y = unit(mu), unit(y)
    cosine = np.clip(mu @ y, -1.0, 1.0)
    tangent = y - cosine * mu
    sine = np.linalg.norm(tangent)
    if cosine < 0 and sine < 1e-8:
        raise ValueError("The log map is ambiguous near antipodal points")
    if sine < 1e-10:
        return tangent
    return np.arctan2(sine, cosine) * tangent / sine


def exp_map(mu, v):
    mu = unit(mu)
    v = np.asarray(v, dtype=float)
    if v.shape != mu.shape or not np.all(np.isfinite(v)):
        raise ValueError("Invalid tangent vector")
    if abs(mu @ v) > 1e-8:
        raise ValueError("Correction must be tangent to mu")
    angle = np.linalg.norm(v)
    return unit(np.cos(angle) * mu + np.sinc(angle / np.pi) * v)


def transport(mu, new_mu, vectors):
    """Parallel transport tangent columns along the shortest sphere arc."""
    mu, new_mu = unit(mu), unit(new_mu)
    denominator = 1 + mu @ new_mu
    if denominator < 1e-8:
        raise ValueError("Transport is ambiguous near antipodal points")
    vectors = np.asarray(vectors, dtype=float)
    return vectors - np.outer(mu + new_mu, new_mu @ vectors) / denominator


def covariance(value, size, positive=False):
    value = np.asarray(value, dtype=float)
    if value.shape != (size, size) or not np.all(np.isfinite(value)):
        raise ValueError("Invalid covariance shape or entries")
    if not np.allclose(value, value.T, atol=1e-10):
        raise ValueError("Covariance must be symmetric")
    value = (value + value.T) / 2
    minimum = np.linalg.eigvalsh(value).min()
    if minimum < -1e-10 or (positive and minimum <= 0):
        raise ValueError("Covariance must be positive (semi)definite")
    return value


def extrinsic_mean(observations):
    """Normalized arithmetic mean; not generally an intrinsic Frechet mean."""
    return unit(np.mean([unit(y) for y in observations], axis=0))


class VMFFilter:
    """Conjugate vMF measurement fusion with heuristic confidence decay."""

    def __init__(self, initial_mu, kappa=5.0):
        if not np.isfinite(kappa) or kappa < 0:
            raise ValueError("Concentration must be nonnegative")
        self.mu = unit(initial_mu)
        self.eta = float(kappa) * self.mu

    @property
    def kappa(self):
        return np.linalg.norm(self.eta)

    def predict(self, decay=0.98):
        if not 0 <= decay <= 1:
            raise ValueError("Decay must be between zero and one")
        self.eta *= decay

    def update(self, observation, kappa_obs):
        if not np.isfinite(kappa_obs) or kappa_obs < 0:
            raise ValueError("Observation concentration must be nonnegative")
        self.eta += kappa_obs * unit(observation)
        if self.kappa > 1e-12:
            self.mu = self.eta / self.kappa
        # At zero concentration the direction is arbitrary: keep the old one.
        return self.mu.copy(), self.kappa


class RiemannianSphereEKF:
    """Local error-state filter with identity appearance observation.

    E holds the current tangent basis. Supply R in this exact basis.
    The observation-noise approximation is local and independent of the prior.
    """

    def __init__(self, initial_mu, initial_var=0.04):
        if not np.isfinite(initial_var) or initial_var <= 0:
            raise ValueError("Initial variance must be positive")
        self.mu = unit(initial_mu)
        self.E = tangent_basis(self.mu)
        self.P = np.eye(self.mu.size - 1) * initial_var

    def predict(self, Q):
        """Keep the mean; add uncertainty in the current tangent basis."""
        self.P += covariance(Q, self.P.shape[0])

    def innovation(self, observation, R):
        R = covariance(R, self.P.shape[0], positive=True)
        z = self.E.T @ log_map(self.mu, observation)
        return z, self.P + R

    def association_score(self, observation, R):
        """Local Gaussian NLL, up to a common constant; lower is better.

        A tutorial score, not a complete MHT likelihood: clutter, priors,
        detection probability and large-angle density corrections are omitted.
        """
        z, S = self.innovation(observation, R)
        distance2 = float(z @ np.linalg.solve(S, z))
        logdet = np.linalg.slogdet(S)[1]
        return distance2, 0.5 * (distance2 + logdet)

    def update(self, observation, R):
        R = covariance(R, self.P.shape[0], positive=True)
        z, S = self.innovation(observation, R)
        K = np.linalg.solve(S, self.P.T).T
        correction = K @ z
        angle = np.linalg.norm(correction)
        if angle >= np.pi - 1e-6:
            raise ValueError("Correction is outside the local chart")
        identity = np.eye(self.P.shape[0])
        remainder = identity - K
        posterior = remainder @ self.P @ remainder.T + K @ R @ K.T
        new_mu = exp_map(self.mu, self.E @ correction)
        new_E = transport(self.mu, new_mu, self.E)
        # First-order reset for log_new(exp_old(correction + error)),
        # expressed in the parallel-transported basis. Along the correction
        # the derivative is 1; in perpendicular directions it is sinc(angle).
        reset = identity
        if angle > 1e-10:
            direction = correction / angle
            sinc = np.sinc(angle / np.pi)
            reset = sinc * identity + (1 - sinc) * np.outer(direction, direction)
        self.P = reset @ posterior @ reset.T
        self.P = (self.P + self.P.T) / 2
        self.mu, self.E = new_mu, new_E
        return self.mu.copy(), self.P.copy()
How cost changes with embedding dimension

A dense tangent covariance has (d − 1)² entries. For 128D, one Float32 covariance occupies 64,516 bytes (about 63 KiB). A stored basis and intermediate matrices require additional memory; the NumPy example uses Float64 by default.

Dense matrix work can grow roughly cubically with dimension. Actual latency depends on the implementation and hardware. Measure it across realistic track counts and hypotheses. No latency measurements are claimed by this tutorial.
