Calibrating Viewpoint Observation Noise in 128D

Bridging synthetic vehicle datasets and UAS flight telemetry to physical covariance matrices Rt in the Riemannian EKF: contrasting Within-Class Tangent PCA and Tangent Partial Least Squares (T-PLS).

The Calibration Objective

In an aerial tracking pipeline, a UAS observes a target vehicle from variable azimuths φ and elevations θ. Deep visual embeddings (e.g. 128D) lie on the unit hypersphere S127.

Standard Kalman filters require an observation noise covariance matrix Rt. In 128D space, naive isotropic noise forces all dimensions to expand, discarding vehicle identity. To prevent false track loss, we must discover the 2D viewpoint sensitivity subspace on the tangent plane TμS127 and scale its eigenvalues by physical UAS camera telemetry errors.

Theory 01

The Exact Mathematical Bridge to Rt

At any tracking time step t, the UAS has physical sensor telemetry errors from gimbal IMU jitter, altitude uncertainty, and bounding box localization:

Σpose = [ σφ2   0
 0   σθ2 ] ∈ ℝ2×2    (e.g., σφ = 8°, σθ = 3°)

The calibration phase produces a 127 × 2 tangent sensitivity transfer matrix W:

W = [ wφ   wθ ] ∈ ℝ127×2

where wφ = ∂v / ∂φ is the tangent direction swept per radian of azimuth orbit, and wθ = ∂v / ∂θ is the tangent direction swept per radian of elevation climb.

By first-order error propagation, the observation noise covariance matrix Rt fed into the Riemannian Kalman Gain equation K = P(P + Rt)-1 is:

Rt = W Σpose WT + σid2 I127
(Rank-2 Anisotropic Viewpoint Ellipsoid) + (Intrinsic Identity Noise Floor)
Methodology 02

Within-Class Tangent PCA vs. Tangent PLS

Attribute Within-Class Tangent PCA (WC-TPCA) Tangent Partial Least Squares (T-PLS)
Supervision Mode Unsupervised within identity Fully supervised (requires φ, θ labels)
Identity Cancellation Mechanism Centers each vehicle model k around its own Fréchet mean μk before pooling. Maximizes covariance directly against label matrix X = [cos φ, sin φ, θ].
Axis Decoupling Span is correct, but e1 and e2 may be an arbitrary diagonal rotation of azimuth and elevation. Explicitly isolates wφ (azimuth) from wθ (elevation).
Transfer Matrix W Output W = [ √λ1 e1, √λ2 e2 ] W = Regression loading matrix BPLS
Best Practical Role Sanity check: verifying that within-vehicle variance is strictly 2-dimensional. Production tracking filter: cleanly scales variance by separate physical gimbal/heading errors.

Implementation

Python Calibration Pipeline

Side-by-Side: WC-TPCA vs. Tangent PLS Calibration

import numpy as np
from sklearn.cross_decomposition import PLSRegression

def log_map_sphere(mu, y):
    """Riemannian Log-Map from unit vector y onto T_mu(S^{d-1})."""
    cos_t = np.clip(np.dot(mu, y), -1.0, 1.0)
    theta = np.arccos(cos_t)
    if theta < 1e-7:
        return np.zeros_like(mu)
    return (theta / np.sin(theta)) * (y - cos_t * mu)

# =========================================================================
# METHOD A: Within-Class Tangent PCA (WC-TPCA)
# =========================================================================
def calibrate_within_class_tpca(dataset_by_car, d=128):
    """
    dataset_by_car: dict { car_id: [ (y_vector, azim_rad, elev_rad), ... ] }
    Cancels identity by centering each car around its own Frechet mean.
    """
    all_centered_tangents = []
    
    for car_id, samples in dataset_by_car.items():
        embeddings = np.array([s[0] for s in samples])
        # Compute Frechet mean embedding for this vehicle
        mu_k = np.mean(embeddings, axis=0)
        mu_k /= np.linalg.norm(mu_k)
        
        # Project all samples of this car onto its tangent plane
        for y, _, _ in samples:
            v = log_map_sphere(mu_k, y)
            all_centered_tangents.append(v)
            
    # SVD on pooled within-class tangents
    V = np.array(all_centered_tangents) # Shape: (N, 128)
    _, S, Vt = np.linalg.svd(V, full_matrices=False)
    
    # Top 2 principal directions of viewpoint variation
    e1_view = Vt[0]
    e2_view = Vt[1]
    return e1_view, e2_view, S[:2]

# =========================================================================
# METHOD B: Tangent Partial Least Squares (T-PLS) - RECOMMENDED
# =========================================================================
def calibrate_tangent_pls(dataset_samples, global_mu, n_components=2):
    """
    dataset_samples: list of (y_vector, azim_rad, elev_rad)
    Supervised regression against periodic angle coordinates.
    """
    # 1. Feature Matrix V: Tangent vectors relative to reference mean
    V = np.array([log_map_sphere(global_mu, s[0]) for s in dataset_samples])
    
    # 2. Target Label Matrix X: Periodic circular coordinates
    X = np.array([[np.cos(s[1]), np.sin(s[1]), s[2]] for s in dataset_samples])
    
    # 3. Fit PLS Regression
    pls = PLSRegression(n_components=n_components)
    pls.fit(V, X)
    
    # Extract sensitivity loading directions
    # W_view shape: (128, n_components)
    W_view = pls.x_loadings_
    w_azim = W_view[:, 0] / np.linalg.norm(W_view[:, 0])
    w_elev = W_view[:, 1] / np.linalg.norm(W_view[:, 1])
    return w_azim, w_elev

# =========================================================================
# RUNTIME: Assemble R_t for Riemannian EKF at Tracking Time
# =========================================================================
def build_runtime_covariance_R(y_obs, w_azim, w_elev, sigma_az_rad, sigma_el_rad, sigma_id=0.03):
    """
    Projects calibrated sensitivity vectors to local tangent space of y_obs
    and computes full 127x127 observation noise covariance R_t.
    """
    # Project vectors onto tangent space of y_obs
    def project_tangent(vec, base):
        t = vec - np.dot(vec, base) * base
        return t / (np.linalg.norm(t) + 1e-9)
        
    u_az = project_tangent(w_azim, y_obs)
    u_el = project_tangent(w_elev, y_obs)
    
    # Build local tangent basis E (128, 127)
    idx = np.argmin(np.abs(y_obs))
    arb = np.zeros(128); arb[idx] = 1.0
    A = np.random.randn(128, 127)
    A = A - np.outer(y_obs, y_obs @ A)
    E, _ = np.linalg.qr(A)
    
    # Express in 127D coordinates
    z_az = E.T @ u_az
    z_el = E.T @ u_el
    
    # R_t = var_az * (z_az z_az^T) + var_el * (z_el z_el^T) + var_id * I
    R_tangent = ((sigma_az_rad**2) * np.outer(z_az, z_az) +
                 (sigma_el_rad**2) * np.outer(z_el, z_el) +
                 (sigma_id**2) * np.eye(127))
    return R_tangent
